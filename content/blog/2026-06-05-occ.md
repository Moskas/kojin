# Day 1
As two of the three ThinkPads have Japanese layout that I have partialy neglected in my NixOS config (I had configured the 106JP layout but nothing more).  
## Japanese keyboard and input
My first task was to add proper JP106 keyboard config and add Japanese character input with fcitx5 and mozc.  
Thankfully the setup is simple and well described on [NixOS Wiki](https://wiki.nixos.org/wiki/Fcitx5)
```nix
{
  i18n.inputMethod = {
    enable = true;
    type = "fcitx5";
    fcitx5.addons = with pkgs; [
      fcitx5-mozc
      fcitx5-gtk
    ];
  };
}
```

Now I can write in Japanese with simple toggle やった!  
*Not that I'm fluent enough in it to write anything more than single words*

## Blog adventure
But alas I've decided to work on my blog and have some local preview and to my surprise *bun* package that I had declared in my nix devshell works on my desktop and T480 and crashes on my older laptops. After a little bit of research the solution was simple, kinda.  
Main *bun* package requires at leath 4th Gen Intel processor due to need of AVX and AVX2 instructions. There is however a *bun-baseline* version that works on cpus as old as 1st gen Intels but there is a catch, nixpkgs doesn't packge the baseline package apart for darwin for whatever reason.  
So I had to make a package myself and add it to my [mospkgs](https://github.com/Moskas/mospkgs). 
![screenshot of bun running on i5-3320M](../static/img/bun.png)
Now I can write and see a preview of my blog even on my older machines.
