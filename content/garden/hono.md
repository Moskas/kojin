Hono is a lightweight web framework for the edge. It runs on [[bun]], Deno, Cloudflare Workers, and anywhere with a Web Standards-compatible fetch handler.

## Features

- JSX support for server-side rendering without a client-side framework
- Minimal middleware, composable by design
- First-class TypeScript
