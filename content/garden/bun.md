Bun is a fast JavaScript runtime built on JavaScriptCore. It ships with a bundler, test runner, and package manager built in.

This site runs on Bun. See also [[hono]] for the web framework layer.

## Why Bun

- TypeScript runs natively — no separate compile step
- `bun:sqlite` gives a zero-dependency SQLite binding
- `bun build --compile` produces a single self-contained binary
